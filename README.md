# 出游分账小程序

用于朋友出游的共享记账微信小程序：多人记录支出，按实际参与者均摊费用，生成全局简化转账清单。**不直接收付款，不提供自动到账验证。**

## 当前状态

已完成第一版需求、设计与开发任务规划，目前仓库主要包含项目文档，业务代码尚未开发。云环境、个人主体服务类目及上架资格仍需核验；未开通付费资源、未提审或发布。

## 第一版功能

- 创建活动，分享邀请朋友加入同一个账本。
- 记录付款人、消费金额、实际参与分摊的人。
- 按参与者均摊，金额精确到分。
- 全局抵消后生成“谁向谁付多少钱”的结算方案。
- 正式结算锁账，自行转账后由付款人标记、收款人确认。
- 重开账时保留已经确认的还款，重新计算剩余差额。
